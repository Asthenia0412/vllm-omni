# Agent entry points

Read [CONTRIBUTING.md](CONTRIBUTING.md) before contributing.
Use the relevant [repository skill](.claude/skills):
[precheck-pr](.claude/skills/precheck-pr/SKILL.md) for author self-checks, or
[review-pr](.claude/skills/review-pr/SKILL.md) for independent reviews.
Before issue triage or PR work, read relevant
[review and issue lessons](docs/contributing/ci/lessons.md) and verify their
evidence against the current revision.
