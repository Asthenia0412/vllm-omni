修复
====
observer.code_fingerprint(code) 使用 python_typed_code_fields_v1：
- 确定性 typed JSON 编码上述 18 个字段及递归 nested code/constants。
- bool 与 int 分型，float/complex 保留 IEEE 字节，bytes 与 str 分型。
- frozenset 按编码排序；不依赖对象 identity、intern 或引用共享图。
- 包含 Python cache tag、文件名、行号/行表、异常表及 flags。
- 遇到未知 constant 类型直接拒绝。

expected hash 仍由已 pin 原始源码独立 compile 推导；不把观察到的实际 hash
直接作为 expected，不跳过 guard。source SHA、运行期间 code object identity、
原 module globals/API identity 检查均保留。

新 receipt 明确记录 code_fingerprint_method。observer/wrapper schema 与 wrapper
method 升为 v2，旧 v1 raw-hash receipt 不能进入新 profile 的正确性授权链。
frozen diagnose_qk_host_dependencies.py 与运行时源码均未修改。
