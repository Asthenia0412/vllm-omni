2. Stream and consumer dependency boundary

admitted() requires current device = raw device, current stream = default, and
no capture. native_impl records and enqueues its callback using the same captured
S. The ordinary native ops, metadata view construction and Lease constructor
do not introduce a stream context switch on this canonical model path. Lease
captures the current stream after the call. validate_padded_send still requires
current stream == lease.stream before allowing the unchanged collective; C++
still checks exact source/owner metadata and captured pointers. No current-stream
guard, device guard, poison check or single-use state transition is removed.

The proposal relies on this admitted canonical path, not on a new promise that
any arbitrary consumer/custom tensor hook may switch streams without admission.
HCCL and receive order remain owned by original all_to_all_5D in comm.py; the
patch does not substitute a custom collective or modify its group/async mode.

A future C++ front admission could own immutable construction policy, source

StorageImpls. Per-view checks, expected raw/send pointer association, default

Moving policy/gamma/coefficient validation to once-per-forward is NOT yet proven:
SharedCoefficients fields and config dictionaries are mutable, and inference

changes; merely trusting a repeated generation integer would weaken admission.

exported API; the current wheel's public Python getters cannot be replaced by
guessed symbols or a raw registry interpretation. Keep these checks unchanged
for this single-variable candidate.
