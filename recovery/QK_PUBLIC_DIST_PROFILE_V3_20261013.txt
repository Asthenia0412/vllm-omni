Scope and lifecycle
Only new files: observe_qk_public_dist.py, diagnose_qk_public_dist.py, and its
CPU test. Frozen v2 and runtime files remain unchanged. Reuse the frozen outer
run_arm and InstrumentedCall bytecode with a private constructor replacement.
Keep the original collective, HCCL group, stream, async flag, owner references,
input arithmetic, 20 warm calls and 60 diagnostic calls. Keep existing before/
after-call NPU sync; add no device operation or intermediate synchronization.

sys.setprofile is enabled only while calling the original public Python API,
in the current Python thread. Reject an existing profiler before that call.
Restore None on normal and exceptional exit. A foreign replacement is preserved
and produces terminal diagnostic failure, never accepted as a complete row.
CPython can remove a callback that raised; this is recorded as a failed row even
though the original None state is restored. All errors follow the existing
owner quarantine and worker retirement policy. No retry or native fallback.

The callback uses fixed integer arrays. It retains no frame, tensor, Work,
exception, or traceback and never reads f_locals. Group ID is checked against
the original collective arguments. The actual body frame ID, exact source/code,
CALL offsets, and C function object identities align both events with the pinned
work=result; work.wait() dataflow. It does NOT directly observe a Work instance
ID, because CPython provides the underlying C function, not the bound Work.

Six marks per row: body_call, alltoall_c_call, alltoall_c_return, wait_c_call,
wait_c_return, body_return. Five disjoint intervals partition this body span.
The body span lies inside v2's public_dist_call and has the same native TID.
Never add these intervals to the enclosing collective/public-call durations.
C-call intervals include conversion, profile callback overhead, GIL release and
reacquisition, scheduling, and the binding itself. They are not pure backend or
network time. sys.setprofile observes every Python/C event in this thread while
enabled, even though only six marks are retained. It has nonzero perturbation.
